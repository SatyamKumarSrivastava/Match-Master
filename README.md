# Match Master: A Global Learning Game

Match Master is an interactive educational web game designed to make learning fun through matching activities. Players match flags, historical personalities, monuments, and country-related information.

## Features

* Interactive drag-and-drop gameplay
* Matching activities based on different countries and topics
* Score calculation
* Final result page
* Attractive and user-friendly interface
* Responsive design
* Educational content combined with gaming

## Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – Game logic, drag-and-drop functionality, and score calculation

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing the game.

## Purpose

The purpose of Match Master is to combine **education and interactive gaming** so that users can learn about countries, historical personalities, monuments, and other information in an engaging way.
